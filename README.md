# CSE 6332 Image Gallery

A responsive static website with twelve image-and-description cards, click-to-enlarge viewer, and mobile layout.

## Add the images

Copy at least 12 provided image files into `images/`, naming them `image01.jpg` through `image12.jpg`, or edit the `file` fields in `script.js` to match their real filenames. Replace each placeholder title and description with accurate details about the corresponding image. **Until you do this, the gallery displays placeholders and does not satisfy the image requirement.**

## Preview locally

Run `python -m http.server 8000` from this folder and open http://localhost:8000.
